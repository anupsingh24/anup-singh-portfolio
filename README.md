# anup-singh portfolio

A hand-built static site laid out like a printer's proof sheet. No build step: deploy the folder as-is.

- `index.html` page content
- `style.css` the design system (paper, ink, vermilion; Gloock, Newsreader, Martian Mono)
- `main.js` the compare/merge diff, figure counters, and the publish-to-regions contact reveal
